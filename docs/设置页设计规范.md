# 设置页设计规范（左侧分类 + 右对齐控件）

> 本文记录 MangaProof 设置对话框 2026-10 这一轮改版后的**布局与交互规范**，
> 供后续新增设置项、以及程序内其它「设置 / 偏好」面板复用。
>
> - 参考实现：`mangaproof/ui/settings_dialog.py`（布局、分页、行）、
>   `mangaproof/ui/widgets.py`（`ToggleSwitch` 胶囊开关）；
> - 回归测试：`tests/test_settings_dialog.py`、`tests/test_toggle_switch.py`；
> - 配色与字号：`mangaproof/ui/theme.py`。

---

## 1. 整体结构

```
┌ 设置窗口 ──────────────────────────────────────────────────────┐
│ ┌────────────────┐  24  ┌────────────────────────────────────┐ │
│ │ 缩放与标注显示 │  24  │ 缩放与标注显示                     │ │ ← 固定页头
│ │ 对比呈现       │  24  │ 画布上的自动缩放与叠加显示         │ │
│ │ 扫描与运行策略 │  24  │ ────────────────────────────────── │ │ ← 1px 分割线
│ │ 返修单参数     │  24  │ 图层自动显示比例： [ 60% ]         │ │ ← 可滚动区
│ │ 快捷键与滚轮   │  24  │ bg 独立比例              ( ●)      │ │
│ │                │  24  │                                    │ │
│ └────────────────┘      └────────────────────────────────────┘ │
│ [恢复默认设置]                                   [确定] [取消] │
└────────────────────────────────────────────────────────────────┘
```

- **侧边栏**：分类导航，宽度固定；点哪一项，右侧只显示那一类设置；
- **页头**：标题 + 一句灰色说明 + 分割线，**滚动时不动**；
- **设置项区**：唯一可上下滚动的部分；
- **底部**：恢复默认设置（左）+ 确定 / 取消（右），任何高度下都可见。

为什么不是「一页平铺 + 一路往下滚」：设置项会持续增加，平铺后找一项要滚动很久；
分类导航把"找"的成本固定成一次点击。

## 2. 几何规范（全部取逻辑像素）

| 项 | 值 | 说明 |
|---|---|---|
| 默认窗口 | **903 × 588** | 横向，**宽高比恒为 43:28（= 860:560）**：改尺寸必须横竖等比。903×588 是 860×560 保持该比例的唯一放大档（+5%），为容纳显示页新增的「自动定位与缩放」一行（多点一行后 560 高的视口只剩 378px，比内容少 4px，会冒出滚动条） |
| 最小窗口 | **720 × 440** | 再窄会把长选项下拉挤到截断 |
| 统一留白基线 `GUTTER` | **24** | 四边内边距、侧边栏↔内容、底部按钮右缘都取它 |
| 侧边栏宽 | **180** | 15px 粗体下最长项「缩放与标注显示 / 扫描与运行策略」实宽 105px |
| 侧边栏内边距 / 项上下内边距 | 4 / 8 | 页头靠「列表边框 1 + 内边距 4」下沉 5px，与第一项文字对齐 |
| 设置项行距 `ROW_SPACING` | **16** | 行与行之间；分割线上下也用它 |
| 文本 ↔ 控件间距 `ROW_LABEL_GAP` | **10** | 下拉框"贴着冒号"的距离 |
| 滚动条间隙 `SCROLL_GAP` | **6** | 有滚动条时控件右缘让出的量 |
| 内容区底部余量 | 14 | 滚到底时最后一行不贴边 |

**右缘基线**：所有行控件（下拉框、输入框、开关、按钮）的右缘都压在
`窗口宽 − GUTTER` 这条线上；底部「确定 / 取消」的右缘也是同一条线。

**左侧**：侧边栏、「恢复默认设置」都从 `x = GUTTER` 开始；内容区文本从
`侧边栏右缘 + GUTTER` 开始。

---

## 3. 页头

- **标题**：15px 粗体，与侧边栏分类项**同字号、同字重、同高**；
  标题标签固定高度 = 侧边栏项行高，文字垂直居中，所以两栏的**文字顶端对齐**；
- **说明**：13px，`COLOR_TEXT_DIM`（#a0a4ab），一句话；宽度不足时自动换行；
- **分割线**：1px，`COLOR_BORDER`（#4a4e54），横跨整个内容列；
  上/下留空各 = `ROW_SPACING`（16px）；
- 三者都属于固定页头，**不随设置项滚动**。

页头与侧边栏第一项的对齐靠"同高 + 垂直居中"实现，不靠写死像素；
换字体、换 DPI 时仍然成立（行高由 `QFontMetrics` 现场算）。

---

## 4. 设置项行

一行 = 左侧文本（统一左对齐）+ 右侧控件。控件有两种排法：

| 排法 | 用于 | 水平规则 |
|---|---|---|
| **填充型** | 下拉框、单行输入框 | 从"本页统一字段列"开始，向右占满到基线 |
| **右对齐型** | 开关、按钮 | 保持自身宽度，贴行右缘 |

**字段列（填充型左缘）**：同一页内取**所有填充行标签文字的最大宽度**，
其余行的文本补足到这个宽度。等价于"左缘对齐到本页最窄的那个下拉框"
（因为右缘都相同）。只统计填充型行——开关行的文案通常更长，算进去会把整列无谓推右。

字段列按页独立计算、按字体度量实时求出，不写死数值：
新增设置项或改文案会自动重排，某一页出现长标签也不会影响其它页。

为什么不直接用 `QFormLayout`：它只能让字段列整体对齐，做不到
"每页自定义列宽 + 控件右缘压基线 + 开关右对齐"这三件事同时成立。

## 5. 胶囊开关（`ToggleSwitch`）

所有「开 / 关」设置项都用它，不用方块勾选框。

| 项 | 值 |
|---|---|
| 控件尺寸 = 轨道尺寸 | **40 × 20**（不要再加 padding，否则右缘比下拉框缩进） |
| 轨道圆角 | **6px**（圆角矩形，不是两端半圆的跑道形） |
| 滑块 | **16 × 16**，四周间隙 **2px** |
| 滑块圆角 | **4px = 轨道圆角 − 间隙**，圆弧与轨道**同心** |

> 滑块圆角必须用"外圆角 − 间隙"而不是照抄外圆角：同半径时两段圆弧不同心，
> 直边间隙 2px、45° 拐角处会变成 2.83px，圆弧→直边的转折点还错开 2px，
> 拐角处会张开一条楔形缝——怎么调半径都不贴合。

配色（跟随暗色主题）：

| 状态 | 轨道 | 滑块 |
|---|---|---|
| 关 | `COLOR_BORDER` #4a4e54 | #c8ccd2 |
| 开 | `COLOR_ACCENT` #4a90d9 | #ffffff |
| 悬停 | 各自提亮一档 | 不变 |
| 禁用 | #33363a | `COLOR_TEXT_DIM` |
| 键盘焦点 | 沿轨道边缘 1px 描边（开态白色 / 关态强调色） | — |

交互（刻意保持简单）：

- **点控件任意位置切换**（`QAbstractButton` click 语义）；聚焦后 **Space** 也切换；
- 滑块**不跟手拖动**：按住拖到控件外松手不会切换，拖到内侧松手只算一次点击；
- `isChecked()` 在点击当拍就是新值，120ms 滑块滑动只是视觉过渡；
- **Enter 不绑定切换**——对话框里 Enter 属于「确定」。

无障碍：开关本身没有文字，`accessibleName` 取所在行的文本。

## 6. 置灰联动

控件被禁用时（如手动对比下的「切换速度」、PNG 下的「JPEG 质量」），
**该行文本一并置灰**，不能只有下拉框变灰。

实现：行组件监听控件的 `EnabledChange` 事件，把同样的禁用状态施加到文本上；
置灰颜色由 `theme.py` 的 `QLabel#settingsRowLabel:disabled` 提供
（全局样式表里的 `color` 会盖掉禁用态调色板，必须显式写 `:disabled` 规则）。

覆盖到的情况：bg 独立比例关闭（两个比例下拉）、对比模式=手动（切换速度）、
页面图像=PNG（JPEG 质量）、非 Windows（控制台开关）、Android（内存策略）。

---

## 7. 滚动

- 设置项区内容不超高时：**滚动条隐藏**，控件右缘压在基线上；
- 需要滚动时：滚动条出现在最右侧，**右缘与「取消」按钮对齐**；
  控件右缘让到 `滚动条左缘 − SCROLL_GAP(6px)`；
- 让位是动态的：滚动条 `Show` / `Hide` 时同步内容右侧内边距（6 ↔ 0），
  不滚动时不会平白少 6px；
- 页头的标题 / 说明 / 分割线在滚动时**坐标不变**。

---

## 8. 按钮与状态语义

- 底部按钮固定为中文：**确定**（左）、**取消**（右）；程序没装 Qt 翻译，
  必须显式 `setText`，与「关于 / 第三方许可」页做法一致；
- **确定**：保存并应用**所有分类**里改过的设置（不是只保存当前页）；
- **取消**（含点窗口 X、按 Esc）：本次所有改动一律丢弃，`Settings` 与打开前一致；
- **恢复默认设置**：复位所有分类的控件（涵盖全部设置项），仍需「确定」才生效；
- 分类页在构造时**一次全部建好并常驻**，`QStackedWidget` 只切显示、绝不重建——
  否则"先在 A 分类改几项、再去 B 分类改几项"时，A 的改动会随控件销毁一起丢失。

---

## 9. 输入细节

- 下拉框一律用 `NoWheelComboBox`：**滚轮不改值**，只能点开选或键盘上下切换；
  滚轮在设置页里只负责滚动内容；
- 控件的 tooltip 会自动复制给行文本，鼠标停在文字上也能看到说明；
- 行文本、说明、标题都左对齐；数字/选项值一律在右列，便于纵向扫读。

新增设置项时的固定动作：

1. 选分类页，用 `_add_row(...)` 加行；下拉/输入框带 `expand=True`，开关用 `ToggleSwitch()`；
2. tooltip 在 `_add_row` **之前**设好（建行时会复制给文本）；
3. 记得在 `apply_to()` / `_reset_defaults()` 里读写该控件；
4. 跑 `tests/test_settings_dialog.py`，它会自动检查字段列对齐、行距、置灰等规范。

## 附录 A：简单设置页可以更轻

同一条规范不要求每个设置面板都长成"侧边栏 + 分割线 + 小标题"的完整形态。
当设置项很少时，这些结构会显得空，可以按下面的判据精简。

**判据（满足其一即可精简）**

- 只有**一个**分类，且设置项 ≤ 10 行；
- 整个面板一屏能放下，用户不需要"导航"；
- 这是一个**子对话框**或某个功能的局部设置，而不是程序级设置中心。

**省什么、留什么**

| 元素 | 完整形态 | 精简形态 | 说明 |
|---|---|---|---|
| 侧边栏 | 必有 | **可省** | 单分类时导航没有意义，内容区直接占满 |
| 页头小标题 | 必有 | **可省** | 窗口标题已说明用途时，"设置"这类标题是重复信息 |
| 灰色说明 | 必有 | **建议保留** | 一行说明能省掉大量 tooltip |
| 分割线 | 必有 | **可省** | 没有"说明 + 设置项"两段结构时无意义；有说明时建议保留 |
| 统一基线 / 行距 / 控件对齐 | 必有 | **必有** | 精简的是结构，不是排版 |
| 胶囊开关 / 置灰联动 / 中文确定取消 / 取消不保存 / 禁滚轮 | 必有 | **必有** | 交互规范不因面板大小而降级 |

**最简形态（无侧边栏、无小标题、无分割线，连说明也省）**

```
┌ 打印设置 ─────────────────────────────────┐
│ 纸张大小：            [ A4            ]   │
│ 方向：                [ 纵向          ]   │
│ 双面打印                        ( ●)      │
│ 彩色                            ( ●)      │
│                         [确定] [取消]      │
└───────────────────────────────────────────┘
```

若保留说明行，**建议同时保留分割线**（说明与可操作区之间需要一条界限），
那就只省侧边栏与小标题，布局按正文第 3 节。

要点：

- 左缘留白仍与右缘一致（完整形态是 24；小窗口可按比例缩到 16，但**左右必须相等**）；
- 行距仍是 16，控件右缘仍是同一条线；
- 窗口宽度可以收窄（建议 520–640），高度按内容走，不强行拉高；
- 如果仍有 2–3 组设置，用「小标题 + 分割线」分段即可，不必上侧边栏；
  **3 组以上或预计会持续增加**，再升级成完整形态。

**已落地的精简形态：生成返修单选项窗口**（`ui/dialogs.py::ReportDialog`）

- 仍用 `QFormLayout`：三行输入（名称 / 页面图像 / JPEG 质量）+ 一个**跨两列**的
  开关行——文案自然落在标签列，胶囊被 stretch 推到字段列右缘；
- 竖向行距 16、横向保持 6：文字贴着控件，两者不再撞成同一个值；
- 开关行抬到与输入行同高（当前 30px）：胶囊本身只有 20px，按自然高度排版会把
  四行文本的节距从 46 压到 41；
- 窗口下部的状态行（警告橙 / 完成绿）**不并入**设置项，单独占一块区域；
- 回归：`tests/test_report_dialog_ui.py`。

**已落地的精简形态 ②：更新页**（`ui/update_dialog.py::UpdateDialog`，2026-10-20）

- 单页 6 行（更新分支 / 更新渠道 / MirrorChyan CDK / GitHub Token / 代理 / 下载限速），
  **无侧边栏、无页头小标题**：窗口标题已说明用途（附录 A 判据）；
- 窗口 **840 × 635（宽高比 1.32）**：760 是"最长提示行不折行"的下限，860 起字段列
  （>700px）显空，840 取中间；高度由内容算出（行高按控件自然 30px，不压缩）；
- 竖向 16 / 横向 6；文本左对齐、字段列 = 本页最长标签 + 6；所有控件右缘压
  `窗口宽 − GUTTER(16)` 这条线，说明 / 分割线 / 状态区 / 进度条 / 按钮同线；
- 灰色说明（`COLOR_TEXT_DIM`）压到两行，第二行是可点的申请链接；下面紧跟
  1px 分割线（`setFrameShape(NoFrame)` + `setFixedHeight(1)` + `background: COLOR_BORDER`，
  与设置页 `settingsDivider` 同款），分割线之后才是输出区（提示行 / 状态正文 / 进度条）；
- 行文本由 `_add_row()` 记录，`_set_form_enabled()` 时与控件**一起置灰**
  （`QLabel#updateRowLabel:disabled`）；控件 tooltip 会复制给行文本；
- 没套用的条款：胶囊开关（本页无开关型设置）、滚动条让位（表单固定 6 行、不滚动）、
  「确定 / 取消」（本页按钮语义由需求 §11.7 定义：保存并检查更新 / 下载 / 清理 / 取消）；
- 回归：`tests/test_update_dialog.py`（`test_form_spacing_matches_settings_spec` 一族）。

## 附录 B：落地前检查清单

- [ ] 左边文本统一左对齐，右边控件右缘压同一条基线；
- [ ] 同一页的下拉框/输入框左缘一致（列宽 = 本页最长标签 + 10）；
- [ ] 行距 16；页头与首行之间按分割线规范（16 / 1px / 16）；
- [ ] 开关用胶囊控件，点按切换、不跟手拖动，滑块圆角 = 轨道圆角 − 间隙；
- [ ] 控件禁用时该行文本一并置灰；
- [ ] 下拉框不响应滚轮；
- [ ] 内容可滚动时滚动条右缘与「取消」对齐，控件让出 6px；不需要滚动时自动隐藏；
- [ ] 页头（标题 / 说明 / 分割线）滚动时不动；
- [ ] 「确定 / 取消」为中文；确定保存全部改动，取消全部丢弃；
- [ ] 分类页只建一次，切页不重建控件。
